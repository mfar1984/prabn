# Pembentangan Kick-Off Projek PRABN

Pakej produksi pembentangan Mesyuarat Kick-Off bagi projek pengubahsuaian Ruang Pejabat Transit PRABN, Ibu Pejabat JPS Malaysia, Cyberjaya.

## Penggunaan

- Buka `index.html` menggunakan Google Chrome atau Microsoft Edge untuk versi interaktif dan beranimasi.
- Gunakan kekunci anak panah untuk menukar slaid, `F` untuk skrin penuh, dan `P` untuk mencetak.
- Buka `Presentation_Kick_Off_JPS_PRABN_Ansar.pdf` untuk versi PDF statik 16:9.

## Kemas kini

Klon kali pertama:

```powershell
git clone https://github.com/mfar1984/prabn.git
```

Ambil kemas kini seterusnya dari dalam folder repositori:

```powershell
git pull
```

Repositori ini mengandungi produk produksi dan aset yang digunakan oleh pembentangan sahaja. Dokumen kerja, arkib sesi, fail pratonton, skrip pembangunan dan versi draf tidak disertakan.
